# LoadTimeWeaver 등록하기

`LoadTimeWeaver`는 스프링이 자바 가상 머신(JVM)으로 클래스가 로드될 때 동적으로 클래스를 변환하는 데 사용된다.

Load-time-weaving을 활성화하려면 다음 예시와 같이 `@Configuration` 클래스 중 하나에 `@EnableLoadTimeWeaving`을 추가하면 된다.

```java
@Configuration
@EnableLoadTimeWeaving
public class AppConfig {
}
```

또는 XML 설정의 경우 `context:load-time-weaver` 요소를 사용할 수 있다.

```xml
<beans>
    <context:load-time-weaver/>
</beans>
```

ApplicationContext에 대해 설정되면, 해당 ApplicationContext 내의 모든 빈은 load-time-weaver 인스턴스에 대한 참조를 받아 LoadTimeWeaverAware를 구현할 수 있다. 이는 특히 JPA 클래스 변환을 위해 load-time weaving이 필요할 수 있는 [스프링의 JPA 지원](https://docs.spring.io/spring-framework/reference/data-access/orm/jpa.html)과 함께 사용할 때 유용하다. 자세한 내용은 [`LocalContainerEntityManagerFactoryBean`](https://docs.spring.io/spring-framework/docs/6.1.11/javadoc-api/org/springframework/orm/jpa/LocalContainerEntityManagerFactoryBean.html) 자바독을 참조하라. AspectJ load time weaving에 대한 자세한 내용은 스프링 프레임워크에서 AspectJ를 사용한 load-time weaving을 참조하라.
